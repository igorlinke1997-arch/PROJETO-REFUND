# Projeto Refund

## 📋 Sobre o projeto

O Refund é um sistema web de solicitação de reembolso de despesas, desenvolvido como atividade prática de programação web.

O projeto permite cadastrar despesas, selecionar categorias, informar valores e visualizar o total das solicitações.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ⚙️ Funcionalidades

- Cadastro de despesas.
- Seleção de categorias.
- Exibição da lista de despesas.
- Cálculo automático do valor total.
- Contador de despesas cadastradas.
- Remoção de despesas.

## 💻 Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize o Live Server.
